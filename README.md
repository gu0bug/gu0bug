### 👨‍💻 关于我 / About Me

专注于 **AI Workflow 编排、企业级系统产品化、软硬件极客工具与数据驱动型产品基础设施**。
坚持 **人机协同共创（AI Pair Programming）** 与 **“干中学（Learning by Doing）”** 的工程闭环——由真实业务与用户痛点定义关键架构决策，通过与 AI 双向启发完成原理探究、边界测试与代码落地。

- 🔭 **正在构建**：[PatchCat](https://github.com/gu0bug/PatchCat) —— 为 AI 构建者打造的开源 Prompt 编排与工作流引擎
- 💡 **硬件/极客玩具**：[kindle-weather-station](https://github.com/gu0bug/kindle-weather-station) —— 墨水屏双语时钟与天气看板
- 🧠 **工程原则**：不迷信黑盒，深挖原理；注重状态切片与极端边界测试；保持谦逊、求真与开源开放
